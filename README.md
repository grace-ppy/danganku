# 悦龄 · 抗衰工作室交互原型

“悦龄 / AGEWELL”是原型暂定名，可替换为正式品牌。为以35–45岁女性为主的抗衰工作室设计。

店主工作台和顾客护理空间已拆分为两个固定入口，不再在页面内切换。顶部提供日间与夜间配色。日间使用奶油白、浅香槟和深棕正文；夜间使用提亮的暖棕、香槟金和暖白正文。首次默认日间，选择保存在单独的浏览器偏好中，刷新后保留，不影响客户记录或图片。

这是系统框架与视觉原型，不是已上线的客户管理后台，也不是正式微信小程序。全部客户、服务和报告都是模拟数据，操作保存在当前浏览器的 localStorage，请勿输入真实客户资料。两个链接仅用于界面分流，不构成正式身份认证或权限隔离。

## 在线入口

- 店主工作台（当前重点）：`https://grace-ppy.github.io/danganku/owner/`
- 顾客护理空间（保留现有原型）：`https://grace-ppy.github.io/danganku/customer/`
- 根网址会自动进入店主工作台。

## 页面

- 店主端：今日工作台、客户档案、预约安排、回访待办、转介绍、经营回顾。
- 顾客端：我的计划、阶段记录、预约申请、推荐朋友。
- 学员端：后续培养框架预览。

## 可体验的流程

- 建档并关联介绍人；按称呼、诉求或来源搜索客户。
- 记录服务、客户反馈、内部判断依据；可同时创建回访待办。
- 查看客户时间轴和阶段报告；顾客视图不显示内部判断笔记。
- 创建预约或从顾客端申请；店主确认时检查时间重叠；取消保留记录。
- 填写跟进结果后完成待办，完成后的待办可重新打开。
- 新增和更新直接转介绍关系，防止重复、自我和循环介绍。

照片入口位于“客户档案”和“记录一次服务”。支持初始照、服务照、阶段照，日期与说明、多图预览、点击放大；每次最多6张JPG/PNG/WebP图片，每张不超过10MB。照片默认仅在店主视图展示，勾选“在顾客端展示”后在该客户的阶段记录里可见。服务照片关联相应服务编号。

演示照片以Blob形式保存在当前浏览器的IndexedDB，不上传服务器，不跨设备同步；清理浏览器站点数据会丢失照片。请使用测试图片。此可见范围仅是演示逻辑，不构成正式身份认证。

尚未实现服务器照片存储、微信分享、微信提醒、报告发送或在线支付。

## 运行

静态资源位于 `dist/`，无需安装依赖或构建。使用任意静态服务器托管该目录，例如：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

推送到 GitHub 仓库的 `main` 分支后，`.github/workflows/pages.yml` 会把 `dist/` 自动发布到 GitHub Pages。

演示日期固定为2026-10-13，以便预约与工作台示例保持一致。正式版需使用实际日期和Asia/Shanghai时区。

## 后续实施

接入统一后台、客户身份绑定、服务与预约持久化存储、照片授权、实际数据权限、备份与导出后，才能用于真实运营。店主端与微信小程序共用客户编号和数据来源。开发范围参见上级目录中的《第一版系统方案.md》。
